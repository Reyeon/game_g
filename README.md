# 고전게임 체험관 — 오프라인 팩 (코덱스 작업용)

코딩 수업(생성형 AI 게임잼) 1차시 분석 활동용 게임 모음. **단일 HTML · 완전 오프라인 · API 없음.**

## 시작하기

1. 이 폴더에서 코덱스(Codex)를 실행하면 `AGENTS.md`의 규칙을 자동으로 따릅니다.
2. 최초 1회: `npm install` (테스트용 jsdom만 설치 — 게임 자체는 의존성 없음)
3. 게임 확인: `classic_games_pack.html`을 브라우저로 열기 (더블클릭)

## 코덱스에게 줄 첫 지시문 예시

- "AGENTS.md를 읽고, 백로그 1번 아스테로이드를 추가해줘. 테스트까지 통과시켜줘."
- "탱크 대전을 추가해줘. AI 탱크는 초등학생이 이길 수 있는 수준으로."
- "인베이더가 초등학생에게 너무 어려워. 폭탄 빈도를 낮추고 첫 웨이브를 느리게 해줘."

## 검증

```bash
npm run check   # 문법
npm run smoke   # 전 게임 자동 실행 테스트
```

배포는 `classic_games_pack.html` 파일 하나만 전달하면 끝입니다.
